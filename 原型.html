TCP 三次握手的具体过程？

回答

TCP 三次握手是建立 TCP 连接的过程：

① SYN：客户端 → 服务器，SYN=1, seq=x

② SYN+ACK：服务器 → 客户端，SYN=1, ACK=1, seq=y, ack=x+1

③ ACK：客户端 → 服务器，ACK=1, seq=x+1, ack=y+1

连接建立完成。

引用来源
谢希仁《计算机网络》§5.2

解释 TCP 三次握手的过程
Q

TCP 三次握手（Three-Way Handshake）

建立 TCP 连接前，双方通过三个报文段完成连接建立：

第一步（SYN）：客户端 → 服务器
SYN=1, seq=x（随机初始序号）
客户端进入 SYN_SENT 状态

第二步（SYN+ACK）：服务器 → 客户端
SYN=1, ACK=1, seq=y, ack=x+1
服务器进入 SYN_RCVD 状态

第三步（ACK）：客户端 → 服务器
ACK=1, seq=x+1, ack=y+1
连接建立，进入 ESTABLISHED 状态

CLOSED → SYN_SENT → ESTABLISHED
📖 参考：谢希仁《计算机网络》§5.2 · 王道考研系列
我
那四次挥手呢？
Q

TCP 四次挥手用于释放连接：

① 客户端 FIN=1, seq=u → FIN_WAIT_1

② 服务器 ACK=1, seq=v, ack=u+1 → CLOSE_WAIT
客户端 → FIN_WAIT_2

③ 服务器 FIN=1, seq=w, ack=u+1 → LAST_ACK

④ 客户端 ACK=1, seq=u+1, ack=w+1 → TIME_WAIT（2MSL）

📖 参考：谢希仁《计算机网络》§5.2

📖 复习模式

Cache 组相联映射中，...需要多少位索引？

💡 解析

组相联映射中，组索引位数 = log₂(组数)。设 Cache 有 64 块，每组 4 路，则组数 = 64/4 = 16，索引位数 = log₂(16) = 4 位。
